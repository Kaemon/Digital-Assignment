## ✨ Features

- **Home** — Hotel landing page with overview and imagery
- **Room Availability** — Browse and check available rooms
- **Events** — View hotel events and activities
- **Direction** — Location and directions to the hotel
- **Cleaning** — Housekeeping management page

## 🚀 Getting Started

### Prerequisites
- Python 3.x
- Flask

### Installation

```bash
# Clone the repository
git clone https://github.com/Kaemon/Digital-Assignment.git
cd Digital-Assignment

# Create and activate virtual environment
python3 -m venv venv
source venv/bin/activate  # On Mac/Linux

# Install dependencies
pip install flask

# Run the app
python3 main.py
```

Then open your browser and go to `http://127.0.0.1:5002`
